# Portfolio web — Nadya Sacchi

Web responsive de una sola página basada en el portfolio PDF de 2026.

## Archivos
- index.html — estructura y textos
- styles.css — diseño responsive
- script.js — menú móvil
- assets/ — imágenes de perfil y muestras de proyectos

## Publicar
Puedes subir esta carpeta a Netlify, GitHub Pages, Vercel o cualquier hosting estático.
No necesita servidor ni base de datos.

## Nota
Los proyectos del portfolio están presentados como muestras profesionales con datos ficticios, tal como indica el documento original.
